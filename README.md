## Proyectos

### ⭐ [Criba](https://github.com/OnicarN/Criba) · *proyecto principal*
SaaS full stack que analiza currículums frente a vacantes con IA, para que los equipos de selección lean menos currículums y entiendan mejor cada uno.
- Subida de PDF, DOCX y TXT con procesamiento individual y seguimiento de progreso.
- Ranking, informes, comparativa de candidatos, estado y notas, y exportación a CSV y PDF.
- Seguridad: BCrypt, JWT, aislamiento de datos por cuenta, bloqueo tras intentos fallidos, CORS y CSP, y clave de IA solo en el servidor.
- Modelo SaaS con planes, límites aplicados en el servidor y panel de uso.

`Java 17` `Spring Boot 3` `PostgreSQL` `React 18` `Vite` `Google Gemini` `Docker`

### 🗓️ [TurnoYa](https://github.com/OnicarN/TURNOYA) · *en desarrollo*
Web para pequeños negocios: el cliente reserva cita escaneando un QR, sin registrarse, y el día de la cita ve en tiempo real si el negocio va con retraso.
- Clean Architecture con dominio en Java puro, separado de JPA.
- Cálculo del retraso en cadena y actualizaciones en directo con WebSockets.
- Doble reserva imposible gracias a un índice único parcial en PostgreSQL.
- Privacidad por diseño (RGPD): datos personales mínimos y borrado al terminar la cita.

`Java` `Spring Boot 4` `PostgreSQL` `Flyway` `WebSockets` `Angular` `Docker`

### [Invoice Intelligence API](https://github.com/OnicarN/invoice-intelligence-api) · *en desarrollo*
API REST para gestionar y procesar facturas, con integración de IA prevista para extraer datos estructurados.

`Java 21` `Spring Boot` `PostgreSQL` `JPA` `Flyway` `JWT` `Docker`

### [ConvertMe](https://github.com/OnicarN/CONVERT-ME-)
Aplicación web full stack para convertir imágenes, audio y vídeo entre formatos, con API REST en Spring Boot y despliegue multicontenedor.

`Java 17` `Spring Boot 3.2` `Docker Compose` `Nginx` `FFmpeg`

### [WibuChat](https://github.com/OnicarN/Wibu-Chat)
App Android de mensajería en tiempo real con chat individual y grupal, cifrado AES de extremo a extremo y asistente de IA con la API de Gemini.

`Android` `Java` `Firebase` `Cloud Functions` `Gemini API`
